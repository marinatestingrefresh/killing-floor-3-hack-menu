## 🧩 About

**Killing Floor 3 Companion** is a curated list of Killing Floor 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, specimen tracker, wave readout
- **Quality-of-Life Helpers** — loadout catalog, perk manager, overlay notes
- **Research Notes** — wave layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Wave Tracker — practice from any wave checkpoint
- Specimen Hitbox Notes — visualize specimen hitboxes
- Replay Notes — record and review run segments
- Playback Speed — adjust practice playback for study (0.1x to 5x)

### Wallhack
- Weapon Catalog — browse weapons, attachments, skins
- Custom Loadout Notes — organize perk cosmetics
- Sight Visibility — improved ADS clarity

### Aimbot
- Practice Mode Notes — segment study on any map
- Wave Control — manually start or pause waves in practice
- Combo Buffer Notes — chain complex maneuvers in the editor
